# Impostor Volleyball

제공된 캐릭터·맵 이미지가 적용된 배구 게임입니다. Node.js 24 LTS를 권장합니다.

## 실행
```sh
npm ci
npm run dev
```
배포용 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`입니다. `dist/` 전체를 GitHub Pages 같은 정적 호스팅에 올리세요. `index.html` 더블클릭 대신 웹 주소로 실행합니다. Pages Actions 워크플로가 포함되어 있습니다.

## 온라인 방·관전
- **온라인 방**에서 이름과 캐릭터를 고르고 **방 만들기**를 누르면 6자리 숫자 코드가 나옵니다. 친구는 같은 게임 웹 주소를 열고 코드로 **방 참가**합니다.
- 선수 최대 8명(1v1~4v4 정원), 관전자 최대 16명입니다. 관전자는 선수 정원과 별개입니다. 같은 캐릭터 색도 선택할 수 있습니다.
- **관전 참가**는 경기 전·진행 중·종료 후 모두 가능합니다. 경기 전에는 방장을 제외한 참가자가 선수/관전을 전환할 수 있습니다. 진행 중 관전자는 조작할 수 없습니다.
- 방장이 시작하며, 진행 중 **경기 설정**으로 맵·시간·팀 모드를 바꿀 수 있습니다. 모두에게 즉시 반영됩니다. 시간을 바꾸면 남은 시간이 선택한 시간으로 재설정되고 점수는 유지됩니다. 현재 선수 수보다 작은 팀 모드는 선택할 수 없습니다.
- 관전자 퇴장은 경기를 중단하지 않습니다. 선수 퇴장 시 경기가 끝나고, 방장 퇴장 시 방이 닫힙니다. 방장 승계나 진행 중 선수 난입은 지원하지 않습니다.

## 랜덤 랭크전
홈의 **랜덤 랭크전** 또는 온라인 화면의 **랜덤 매치**로 시작합니다. 대기 중인 상대를 찾으면 1v1 / 3분 / Polus로 자동 시작하며 캐릭터도 자동 배정됩니다. 상대가 없으면 공개 방에서 기다립니다. **방 나가기**로 검색을 취소할 수 있습니다. 공개 방 코드로 관전도 가능합니다.

별도 매칭 서버 없이 PeerJS에서 정해진 공개 슬롯 32개(990000~990031)를 순서대로 확인합니다. 이미 경기 중이거나 가득 찬 슬롯은 건너뜁니다. 슬롯이 모두 사용 중이면 재시도 안내를 표시합니다. 실력별 매칭이나 전 세계 대기열 서비스는 아닙니다. 일반 비공개 코드는 000000~989999입니다. 이전 버전과 연결 프로토콜이 달라 모든 참가자가 최신 버전을 사용해야 합니다.

## 랭크와 전적
- **BRONZE → SILVER → GOLD → PLATINUM → DIAMOND → MASTER**, 200 RP마다 승급합니다. 시작은 0 RP입니다.
- 완료된 랜덤 랭크전: 승리 +25 / 패배 −15 / 무승부 +5 RP. RP는 0 미만으로 내려가지 않습니다. 결과는 경기당 한 번만 저장합니다.
- 진행 중 설정 변경 시 해당 경기는 일반전으로 전환되어 RP에 반영하지 않습니다. 랭크전의 나가기 버튼으로 이탈하면 패배로 기록합니다. 단순 연결 끊김·브라우저 강제 종료에 대한 서버 판정은 없습니다.
- AI 경기 전적은 별도 저장하며 RP에 반영하지 않습니다. 비공개 친선전과 관전도 RP에 반영하지 않습니다.
- 상단 랭크 버튼에서 티어·RP·승패·승률·AI 전적을 확인합니다.
- 계정 서버가 없는 **이 기기의 로컬 랭크**입니다. 공인 온라인 순위, 계정 동기화, 조작 방지는 제공하지 않습니다.

## AI 대전
홈에서 **AI 대전**을 선택합니다. 동료와 상대의 빈 자리는 AI가 조작합니다.
- 쉬움: 느린 이동·반응, 큰 위치 오차
- 보통: 중간 이동·반응, 짧은 공 예측
- 어려움: 빠른 이동·반응, 더 정확한 공 예측

AI 대기실이나 상단 설정에서 난이도를 바꿀 수 있습니다. 상단 설정 변경은 진행 중 AI 경기에도 적용됩니다. 온라인 경기에는 AI를 넣지 않습니다.

## 저장·배경음악
이름, 캐릭터, 언어, 경기 설정, 키, 모바일 모드, AI 난이도, 음악 켜기/끄기, 음량, 랭크와 전적을 `localStorage`의 `iv-profile-v1`에 저장합니다. 껐다 켜도 같은 브라우저·게임 주소에서 유지됩니다. 기존 언어·키 설정도 가져옵니다. 저장 값이 손상되면 기본값으로 복구합니다. 브라우저 저장 데이터를 지우거나 다른 기기·브라우저를 사용하면 공유되지 않습니다. 진행 중인 경기 자체를 복구하지는 않습니다.

제공된 `브금.mp3`는 `public/audio/bgm.mp3`로 포함되어 반복 재생됩니다. 첫 클릭/키 입력 후 재생을 시도합니다. 상단 음악 버튼 또는 설정에서 끄기와 음량 조절이 가능합니다. 브라우저의 자동재생 정책을 따릅니다.

## 조작·이미지
방향키 좌우: 이동 / 위: 점프 / Space: 공 치기. 설정에서 키와 터치 버튼을 바꿀 수 있습니다. 모바일 버튼 크기는 설정의 슬라이더로 48~96px 범위에서 조절하고 자동 저장합니다. 진행 중에도 즉시 적용되며 좁은 화면에서는 화면 폭에 맞게 줄어듭니다. 게임 화면과 버튼을 길게 눌러도 텍스트 선택·복사 메뉴가 뜨지 않도록 처리했습니다. 이름·코드 입력칸의 편집/붙여넣기는 유지됩니다. 여러 손가락으로 이동과 점프를 동시에 누를 수 있습니다.

`public/assets/characters/{red,green,yellow,white}/{idle,walk1,walk2,jump}.png`는 투명 배경 160×210이며, 배경 3개는 가운데 기준으로 자른 1280×620 JPG입니다. 원본 ZIP과 MP3는 자료로만 사용했으며 다운로드 폴더의 원본은 변경하지 않았습니다.

## 연결 방식
직접 구매·운영하는 게임 서버 없이 방장 브라우저가 경기 상태를 계산합니다. PeerJS 공용 클라우드와 STUN을 사용하므로 인터넷과 해당 서비스가 필요합니다. 엄격한 NAT/회사망/방화벽에서는 연결이 실패할 수 있으며 별도 TURN 중계는 구성하지 않았습니다. 방장은 경기 중 창을 열어 두세요. 백그라운드에서는 브라우저가 느려질 수 있습니다.

## 검증
```sh
npm test
npm run build
```
`npm test`는 Node.js 24에서 저장 데이터 복구, 전적·RP 계산, 티어, AI 난이도 차이를 검사합니다.

브라우저 통합 검사(미리보기 서버를 먼저 실행):
```sh
npx playwright install chromium
npm run preview
# 다른 터미널
npm run test:online
node tests/preferences.mjs
node tests/results.mjs
node tests/mobile.mjs
```
`TEST_URL`로 기본 주소를 바꿀 수 있습니다. `TEST_CHANNEL=chrome`은 설치된 Chrome을 사용합니다. `results.mjs`는 테스트 브라우저의 애니메이션 시계를 빠르게 진행시켜 실제 경기 종료·전적 중복 방지·양쪽 랭크 결과를 검증합니다. 외부 공용 연결 서비스를 사용하므로 온라인 검사는 인터넷과 해당 서비스가 필요합니다.

## Windows 실행 파일
```sh
npm run dist:win
```
결과는 `release/`에 생성됩니다. Electron Windows 패키징은 이번 변경의 검증 대상에 포함하지 않았습니다.
